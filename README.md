# 9 skills para animar con Claude

Guía gratis en español de [@soydiegoosorio](https://instagram.com/soydiegoosorio) con las 9 skills de su video para animar con Claude Code: qué hace cada una, su enlace y cómo instalarlas.

**Página:** https://diegodoc1111.github.io/skills-animar/

## Las 9 skills (repositorios oficiales)
1. HandDraw — https://github.com/ToBeWin/HandDraw-Skill
2. Claude Animation Base — https://github.com/JohnHeibel/ClaudeAnimationBase
3. Claude Drawing — https://github.com/cloveric/claude-drawing-skill
4. AniDoodle — https://github.com/alexgreensh/anidoodle
5. Motion — https://github.com/LunaAI519/motion-skill
6. Motion Design — https://github.com/iart-ai/motion-design-skills
7. Manim — https://github.com/adithya-s-k/manim_skill
8. JavaScript Animation — https://github.com/iart-ai/javascript-animation-skills
9. Huashu Art Motion — https://github.com/alchaincyf/huashu-art-motion

## Fuentes verificadas (18-nov-2026)
- Descripción, licencia y forma de instalar de cada skill: el README de cada repositorio de arriba (Claude Drawing: 83 estilos sin modelo de imágenes; Claude Animation Base: Clawd y 31 emociones; HandDraw: voz gratis con Edge TTS; AniDoodle: películas con música hechas con código; Motion: Nano Banana + Kling; JavaScript Animation: cero imágenes y banda sonora hecha con código; Huashu: 35 estilos, contenido en chino; Manim: estilo 3Blue1Brown, pide FFmpeg y LaTeX).
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup
- Las imágenes son demos reales hechas con cada skill para el video de Diego.
